trizon은 일본·한국 증권사에 흩어진 주식을 한 화면에서 보는 개인용 대시보드입니다. 매일 열어 전체가 얼마인지, 오늘 얼마나 움직였는지, 어느 증권사와 종목이 끌고 있는지 확인하고, 그 숫자를 증권사 앱과 대조합니다. 주식 화면은 보고만 있어도 긴장되므로, 이 시스템은 바탕을 차분한 중립 회색으로 두고, 색은 숫자와 꼭 필요한 곳에만 써서 숫자가 먼저 읽히도록 짭니다.

## 원칙

- 화면은 중립 회색 톤입니다. 바탕은 연회색 `surface`, 카드·표는 흰 `surface-raised`, 맨 위 요약은 `surface-summary`입니다. 초록은 `brand` 하나뿐이고 주요 버튼·선택 상태·링크·포커스에만 씁니다. 바탕에 색을 깔지 않아서 빨강·파랑 숫자와 초록 버튼이 서로 묻히지 않습니다.
- 빨강·파랑은 숫자에만 씁니다. 상승·이익은 `rise`(빨강), 하락·손실은 `fall`(파랑), 변동 없음은 `flat`입니다. 모든 표면 위에서 4.5:1 이상이 되도록 맞춰 두었습니다.
- 초록은 숫자에 쓰지 않습니다. 미국식으로 초록을 상승으로 읽는 사람이 헷갈리지 않도록, `brand`는 UI에만 씁니다.
- 색만으로 방향을 알리지 않습니다. 손익과 전일 대비에는 언제나 `+`·`-` 부호를 붙이고, 상태에는 언제나 단어를 붙입니다. 빨강과 파랑을 구분하기 어려운 사람도 부호로 읽을 수 있습니다.
- 위에서 아래로 범위가 좁아집니다: 총자산 → 증권사 국가 → 증권사 → 시장 → 종목. 숫자 크기도 `figure-xl` → `figure-md` → 표의 `body-sm`으로 함께 줄어듭니다.
- 깊이는 표면 대비로 냅니다. `surface` 바탕 위에 `surface-raised` 카드를 놓고, 그림자는 다이얼로그처럼 떠 있는 요소에만 `shadow-overlay`로 씁니다.
- 빈 곳도 구조입니다. 보유가 없는 증권사 국가도 자리를 지우지 않고 한 줄로 접어 아래에 둡니다.

## 숫자 표기

- 금액·수량·퍼센트는 모두 고정폭 숫자(`tabular-nums`)로 쓰고, 표에서는 오른쪽 정렬합니다. `figure-*` 스타일과 `tz-num`, `tz-table`에 이미 켜져 있습니다.
- 엔 `¥12,000`과 원 `₩1,234,000`은 정수, 달러 `$182.00`은 소수 둘째 자리까지 씁니다. 미국주식의 소수를 버리지 않습니다.
- 이익·상승은 `+`, 손실·하락은 `-`를 통화 기호 앞에 붙입니다(`-$18.00`). 0은 부호 없이 `0`을 쓰고 `flat` 색으로 둡니다.
- 퍼센트는 소수 둘째 자리까지 쓰고(`+20.00%`), 금액 아래나 옆에 `caption`으로 붙입니다.
- 시세 시각은 시장별로 시계 시각을 씁니다("일본 시세 15:00"). 업로드·동기화 시각은 상대 시간으로 쓰고("3일 전"), 일주일이 넘으면 날짜로 씁니다.
- 총자산 근처에는 언제나 "현금 제외"를 적습니다.

## 글쓰기

- 화면은 한국어이고, 문장은 합니다체로 씁니다. 예: 「시세를 받지 못했습니다」, 「저장되지 않았습니다. 새로고침하면 다시 올려야 합니다」.
- 버튼은 하는 일을 이름으로 씁니다: 「시세 새로고침」, 「데이터 지우기」, 「CSV 올리기」, 「연결」, 「동기화」, 「다시 연결」. 같은 동작은 화면이 바뀌어도 같은 이름을 씁니다.
- 상태는 짧은 명사구로 씁니다: "시세 없음", "연결된 증권사 없음", "환차손익 빠짐", "지원 안 됨", "읽지 못함".
- SBI 화면의 용어(`ポートフォリオ`, `約定履歴`, 特定, NISA)와 일본 종목명은 번역하지 않고 원문 그대로 쓰며, `lang="ja"`로 감쌉니다.
- 오류 문장은 무엇이 일어났는지와 무엇을 하면 되는지를 함께 씁니다. 사과하지 않습니다.

## 색상

- 표면: 바탕 `surface`, 카드·표·다이얼로그 `surface-raised`, 맨 위 요약 `surface-summary`, 트랙·중립 배지 `surface-sunken`. `surface-summary`는 지금 `surface-raised`와 같은 흰색이고, 요약은 색 대신 `figure-*` 크기로 먼저 읽히게 합니다. 빨강·파랑 숫자가 많은 표는 `surface-raised` 위에 둡니다.
- 텍스트: 기본은 `ink`, 보조와 표 머리글은 `ink-2`, 시각·각주·플레이스홀더는 `ink-3`입니다. 셋 다 모든 표면 위에서 4.5:1 이상입니다.
- 브랜드: `brand`는 주요 버튼(`on-brand` 라벨, 호버 `brand-hover`), 선택된 세그먼트, 링크, 포커스 링에 씁니다. `brand-soft`는 정상 배지와 선택 배경입니다.
- `rise`·`fall`은 숫자에만 씁니다. 숫자 뒤에 배경이 필요하면 `rise-soft`·`fall-soft`를 씁니다.
- 주의(`warning`, `warning-soft`, `warning-text`)는 "숫자를 믿기 전에 알아야 할 것"에 씁니다: 시세 없음, 환차손익 빠짐, `約定履歴`으로 추정한 값.
- 오류(`danger`, `danger-soft`)는 읽지 못한 파일, 동기화 실패, 지우기에 씁니다. `danger`는 `rise`와 같은 빨강 계열이므로 숫자에는 절대 쓰지 않고, 언제나 아이콘과 문장이 있는 배너·배지·버튼에만 씁니다.
- 정상(`ok`, `ok-soft`)은 연결됨, 동기화 완료, 파일 반영에만 씁니다. 값은 `brand`·`brand-soft`와 같습니다.
- 선은 표 행과 구분선에 `line`, 컨트롤 테두리에 `line-strong`(3:1 이상)을 씁니다.

## 타이포그래피

- 한 계열만 씁니다. 한국어 UI는 IBM Plex Sans KR(`sans`), 일본 종목명과 SBI 용어는 같은 계열의 IBM Plex Sans JP(`jp`)입니다. 한글·가나·라틴 숫자가 한 계열로 맞습니다. `lang="ja"`를 붙이면 bundle.css가 `jp`로 바꿉니다.
- 금액: `figure-xl`은 총자산, `figure-lg`는 맨 위 손익·변동, `figure-md`는 증권사 국가·증권사·시장 소계에 씁니다.
- 제목: `title-lg`는 증권사 국가, `title-md`는 카드와 다이얼로그, `title-sm`은 시장에 씁니다.
- 본문: 안내문은 `body-md`, 표 셀과 카드 본문은 `body-sm`, 표 머리글과 입력 라벨은 `label`, 시각과 퍼센트 보조는 `caption`입니다. 버튼은 `button-md`·`button-sm`, 배지는 `badge`입니다.
- 한국어는 `word-break: keep-all`로 어절 단위로 줄을 바꿉니다(bundle.css의 `body`에 켜져 있음).
- 웹 폰트는 Google Fonts에서 400·500·600·700을 받습니다.

## 간격, 모양, 레이아웃

- 4px 기반입니다. 카드 안쪽은 `spacing-xl`, 표 셀은 `spacing-md`, 증권사 국가 섹션 사이는 `spacing-2xl`, 페이지 상하는 `spacing-3xl`입니다.
- 반경은 바깥이 클수록 큽니다: 카드·다이얼로그 `rounded-xl`, 배너·업로드 영역·접힌 줄·인셋 `rounded-lg`, 입력 `rounded-md`, 툴팁 `rounded-sm`, 파일 이름 칩 `rounded-xs`, 버튼·배지·세그먼트 `rounded-full`입니다.
- 버튼은 40px(작은 버튼 32px), 표 행은 44px입니다.
- PC 우선입니다. 콘텐츠는 `container-max` 안에서 가운데 정렬합니다. `breakpoint-desktop`보다 좁으면 요약 블록을 세로로 쌓고, 표는 자기 영역 안에서 가로로 스크롤합니다.

## 포커스와 접근성

- 키보드 포커스는 2px 실선 `brand` 외곽선, 2px 간격입니다. 모든 표면 위에서 5:1 이상입니다.
- 상승·하락은 색과 부호로, 상태는 색과 단어로 알립니다.

## 아이콘과 로고

- 아이콘 세트는 아직 정하지 않았습니다. 미리보기의 아이콘은 20px(아이콘 버튼은 24px), 1.75px 선의 임시 글리프이며, 세트를 고르면 같은 크기와 선 굵기로 바꿉니다.
- 로고는 없습니다. 이름은 소문자 `trizon`을 일반 텍스트로 씁니다.

## 단계별로 쓰는 컴포넌트

- 1단계: `Summary`는 엔·달러를 따로 보입니다. 일본 증권사는 `BrokerSection` 안의 SBI증권 카드와 `HoldingsTable`로, 한국 증권사는 접힌 한 줄로 보입니다. CSV는 `Uploader`, 실패는 `Banner`, 지우기는 `Dialog`로 처리합니다.
- 3단계: `Summary` 위에 `SegmentedControl`로 표시 통화를 바꾸고, 한국 증권사는 `BrokerCard`로, 키 입력은 `TextInput`으로 받습니다.
