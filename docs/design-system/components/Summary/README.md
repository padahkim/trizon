# Summary

Summary는 대시보드 맨 위에서 전체 얼마, 산 값보다 얼마, 오늘 얼마를 한눈에 보입니다.

- 바탕은 `surface-summary`, `rounded-xl`. 지금은 카드와 같은 흰색이고, 대시보드에서 가장 먼저 보는 곳이라는 것은 색 대신 `figure-xl` 크기로 알립니다.
- 1단계: 통화를 섞지 않고 엔 블록과 달러 블록을 나란히 둡니다. 각 블록은 이름(`label` `ink-2`), 총평가액(`figure-xl`), 평가손익과 오늘 변동(`Delta`, `tz-kv`)입니다.
- 3단계: 블록 하나로 표시 통화 총자산·총평가손익·오늘 변동을 보이고, 오른쪽 위에 `SegmentedControl`(₩ 원, ¥ 엔, $ 달러)을 둡니다. 연결한 증권사만 합친다는 것을 메타 줄에 적습니다(PRD U30). 환율을 못 받으면 블록을 계좌통화별로 되돌리고 주의 배너를 붙입니다(PRD U32).
- 메타 줄 `tz-summary-meta`: "현금 제외" 배지, 시장별 시세 시각, 마지막 업로드·동기화 시각, 오른쪽 끝에 「시세 새로고침」. 항목은 점으로 잇지 않고 간격으로 나눕니다.
- 시세를 받는 중에는 보유로 계산한 숫자를 먼저 보이고 버튼만 「받는 중」으로 바꿉니다.
- 사용하는 쪽이 제공: 통화별 합계, 손익과 퍼센트, 시각 문자열, 새로고침 처리.
