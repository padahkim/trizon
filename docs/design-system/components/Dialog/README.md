# Dialog

다이얼로그는 되돌릴 수 없는 동작을 하기 전에 한 번 묻습니다.

- 마크업: `tz-scrim`(`overlay` 스크림) 안에 `tz-dialog`(`surface-raised`, `rounded-xl`, `shadow-overlay`, 최대 440px), `role="alertdialog"`.
- 제목은 질문으로(`title-md`): "데이터를 지울까요?". 본문(`body-md` `ink-2`)은 무엇이 사라지는지 씁니다.
- 되돌릴 수 없는 결과가 있으면 본문 아래 주의 배너로 따로 씁니다(PRD U15: 2년보다 오래된 거래).
- 버튼은 오른쪽 정렬, 「취소」(고스트) 다음에 동작 버튼. 동작 버튼은 처음 누른 버튼과 같은 이름(「데이터 지우기」)이며, 파괴적이면 `tz-btn-danger`입니다.
- 열리면 「취소」에 포커스를 두고, Esc와 스크림 클릭은 취소로 처리합니다.
- 쓰는 곳: 데이터 지우기, 증권사 연결 해제, 계정 삭제, 1단계 데이터 옮기기(F2).
- 사용하는 쪽이 제공: 제목, 본문, 경고, 두 버튼의 라벨과 처리.
