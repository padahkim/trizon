# Uploader

업로드 영역은 SBI증권 CSV를 받고, 파일마다 무엇을 반영했는지 알립니다.

- 빈 상태 `tz-drop`: `surface` 바탕, 1px 점선 `line-strong`, `rounded-lg`. 끌어다 놓는 중에는 `is-over`로 테두리를 `ink`로 바꿉니다.
- 받을 파일 두 개의 원래 이름(`ポートフォリオ`, `約定履歴`)을 `tz-file` 칩으로 보이고, 각각 무엇이 들어 있는지와 받는 곳 링크를 적습니다(PRD U1).
- 주요 버튼 「CSV 고르기」는 여러 파일 선택을 받습니다.
- 결과 `tz-results`: 파일마다 한 줄로 상태 배지(반영됨, 읽지 못함), 파일 이름, 무엇이 바뀌었는지를 씁니다. 한 파일이 실패해도 나머지는 반영하고 그렇게 적습니다(PRD U4).
- 처음에는 SBI증권 카드 안에서 크게, 보유가 생긴 뒤에는 카드 머리의 「CSV 올리기」 보조 버튼으로 엽니다.
- 사용하는 쪽이 제공: 파일 선택·드롭 처리, 파일별 결과, 받는 곳 링크.
