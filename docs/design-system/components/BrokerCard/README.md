# BrokerCard

BrokerCard는 3단계에서 API로 연결한 한국 증권사 하나의 상태와 계좌별 합계를 보입니다.

- 머리: 증권사 이름(`title-md`), 상태 줄에 상태 배지와 시각, 오른쪽에 그 상태에서 할 수 있는 동작 하나.
- **연결됨**: 정상 배지(`ok`)와 마지막 동기화 시각, 고스트 「동기화」.
- **동기화 실패**: 오류 배지(`danger`)와 실패 이유(키 만료, 점검 시간, 호출 한도), 보조 버튼 「다시 연결」. 마지막 성공 보유는 그대로 보이고 합계에도 남기며, 그 시각을 적습니다(PRD U27).
- **지원 안 됨**: 중립 배지와 한 문장. 동작 없음(PRD H4).
- 본문은 계좌·시장별 행 `tz-acct`: 왼쪽 이름과 배지(예: "환차손익 빠짐"), 오른쪽 평가액과 평가손익. 종목까지 펼치면 `HoldingsTable`을 씁니다.
- API가 주지 않는 정보는 카드 안에 `caption`으로 적습니다(PRD 열린 질문 7).
- 사용하는 쪽이 제공: 증권사 이름, 상태와 이유, 시각, 계좌 행, 동작 처리.
