# HoldingsTable

종목 표는 한 시장의 종목별 숫자를 증권사 앱과 같은 열 순서로 보이고, 맨 아래에 합계를 둡니다.

- 열: 종목, 보유수량, 취득단가, 현재가, 평가액, 평가손익, 전일 대비. 종목은 왼쪽, 숫자는 모두 오른쪽 정렬이며 `tabular-nums`입니다.
- 머리글은 `label` `ink-2`, 셀은 `body-sm`, 행 높이 44px(`spacing-md`), 행 사이 `line`.
- 평가손익과 전일 대비는 금액 아래 퍼센트를 `caption`으로 쌓고 `tz-rise`·`tz-fall`·`tz-flat`으로 칠합니다.
- 종목 이름은 원문 그대로 `name-ja`(`lang="ja"`). 같은 종목이 特定·NISA로 나뉘면 행을 나누고 계좌구분 배지를 붙입니다(PRD 열린 질문 3).
- 시세가 없으면 현재가를 "—"로 두고, 취득가로 평가해 손익을 `0`(`tz-flat`)으로 보이며 "시세 없음" 주의 배지를 붙입니다. 합계에서 빼지 않습니다(PRD U8).
- 합계 행 `tfoot`: `surface` 바탕, 굵게, "일본주식 합계"처럼 시장 이름을 씁니다.
- 좁은 화면에서는 `tz-table-wrap` 안에서 가로로 스크롤합니다.
- 사용하는 쪽이 제공: 행 데이터(포맷된 문자열과 방향), 합계, 표 이름(`caption`).
