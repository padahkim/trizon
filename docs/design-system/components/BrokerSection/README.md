# BrokerSection

BrokerSection은 증권사 국가(일본 증권사, 한국 증권사) 하나를 묶고, 그 아래 증권사 카드와 시장별 표를 둡니다.

- 머리 `tz-section-head`: 제목 `title-lg`, 오른쪽에 통화별 소계 `figure-md`(1단계는 엔·달러 따로, 3단계는 표시 통화 하나).
- 증권사마다 `tz-card` 하나. 머리에 증권사 이름(`title-md`), 상태 줄(`tz-status`: 마지막 업로드·동기화 시각, 상태 배지), 오른쪽에 「CSV 올리기」나 「동기화」.
- 카드 안은 시장별 `tz-market` 블록(일본주식, 미국주식, 한국주식)으로 나누고 각각 `HoldingsTable`을 둡니다. 시장 머리에는 그 시장의 시세 시각과, 숫자에 대한 주의 배지를 붙입니다.
- 보유가 없는 증권사 국가는 지우지 않고 `tz-collapsed` 한 줄로 접어 아래에 둡니다: "연결된 증권사 없음" 또는 "CSV 올리기"(PRD 열린 질문 10). 3단계부터 이 줄 오른쪽에 「연결」을 둡니다.
- 섹션 사이는 `spacing-2xl`.
- 사용하는 쪽이 제공: 국가 이름, 소계, 증권사 카드들, 비었을 때의 한 줄 문구.
