# Working Library

다음에 또 쓸 자산을 어디에 두고 언제 만드는지 정한다. 이유: docs/decisions/009-working-library.md

새 스킬·스크립트·틀을 만들기 전, 같은 작업을 두 번째로 하고 있다고 느낄 때, PR 본문을 쓸 때 읽는다.

## 1. 자산과 자리

| 자산 | 자리 | 목록 |
|---|---|---|
| 스킬: 반복 작업의 절차 | `.agents/skills/<이름>/SKILL.md` | `.agents/skills/` 폴더 |
| 훅·CLI: 결정론적 확인과 조회 | `scripts/`, 도구별 훅 설정은 가리키기만 한다 | 루트 `AGENTS.md`의 "명령" |
| MCP | 없음 | — |
| 지침 | 루트·폴더별 `AGENTS.md`, `docs/` | 루트 `AGENTS.md`의 "폴더별 지침" |
| Golden Rules | `docs/golden-rules.md` | — |
| 결정 기록 | `docs/decisions/` | 루트 `AGENTS.md`의 "결정 기록" |

목록은 "목록" 칸에 적은 곳 한 군데에만 둔다. 이 문서에 자산을 다시 나열하지 않는다.

## 2. 자리별 규칙

### 스킬

- 원본은 `.agents/skills/<이름>/`이다. Codex와 Antigravity가 여기서 읽는다.
- Claude Code는 `.claude/skills`(→ `../.agents/skills` 링크)로 같은 파일을 읽는다. 링크 안에서 파일을 만들거나 고치는 것은 원본을 고치는 것과 같다.
- `SKILL.md` frontmatter에는 `name`과 `description`만 쓴다. 도구 전용 필드는 다른 도구에서 다르게 동작하므로 쓰지 않는다.
  - `name`은 폴더 이름과 같게 쓴다. `npm test`가 확인한다.
  - `description`에는 "언제 쓰나"를 쓴다. 에이전트는 이 문장을 보고 스킬을 고른다.
- 본문에는 절차만 쓴다.
  - 규칙은 원본 문서의 경로를 가리킨다.
  - 실행할 로직은 `scripts/`에 두고 `npm run`으로 부른다.
  - 형식이 정해진 문서의 틀은 스킬 폴더에 둔다(`template.md`).
- 부르는 법: Claude Code는 `/이름`, Codex는 `$이름`이다. `description`에 맞는 요청이면 에이전트가 알아서 부르기도 한다.

### 훅·CLI

- 로직은 `scripts/`의 파일 하나에 둔다. `.claude/settings.json`과 `.codex/hooks.json`은 그 스크립트를 가리키기만 한다(docs/decisions/007-agent-stop-check.md).
- 판정 로직은 가짜 입력으로 `scripts/*.test.ts`에서 검사한다. 네트워크 없이 `npm test`로 돈다.

### MCP

- 지금은 없다. CLI로 되는 일은 `scripts/` + `npm run`으로 만든다.
- 만들게 되면 로직은 `scripts/`에 두고, 도구별 설정(Claude Code는 `.mcp.json`)이 같은 명령을 가리키게 한다. 도구별 설정 위치는 그때 공식 문서로 확인한다.
- 새 npm 의존성이 필요하면 추가하기 전에 사용자에게 묻고, 결정 기록을 남긴다.

## 3. 언제 만드나

1. 같은 작업을 두 번째로 손으로 하고 있으면 자산으로 만든다. 처음에는 만들지 않는다. 첫 실행의 기록(PR, 커밋, 세션)이 명세가 된다.
2. 에이전트 메모리, `~/.claude`, `~/.codex`에 있는 규칙이나 스킬을 이 리포 작업에 쓰고 있으면 리포로 옮긴다. 다른 PC나 다른 도구에서는 보이지 않는다.
3. 다음에 또 할 것이 보이지만 아직 한 번뿐이면 4절 후보에 적는다. 만들지는 않는다.
4. 모양은 이렇게 고른다.
   - 빠뜨리면 사고가 나는 확인: 훅·테스트
   - 따라 하는 절차: 스킬
   - 알아야 할 지식: `docs/`, 폴더별 `AGENTS.md`
5. 만들었으면 PR 본문의 "Working Library"에 적는다. 4절 후보에 있던 것이면 후보에서 지운다.

## 5. PR 회고

PR 본문 끝에 아래 절을 쓴다. `.github/pull_request_template.md`가 자리를 잡아 둔다. `gh pr create --body`로 본문을 직접 쓸 때도 넣는다.

```markdown
## Working Library

- 만든 것: 없음 | 자산 이름과 자리
- 다시 쓴 것: 없음 | 이번 작업에 쓴 기존 자산
- 후보: 없음 | 4절에 더하거나 지운 것
```

- 해당하는 것이 없으면 "없음"이라고 쓴다. 비워 두지 않는다.
- "다시 쓴 것"이 라이브러리의 재사용 기록이다. 만든 스킬이 다시 쓰이는지는 이 기록으로 판단한다(docs/decisions/009-working-library.md "다시 볼 조건").
