# 004. 시세는 Yahoo 비공식 API로 받고, 환율은 Frankfurter로 대비한다

- 상태: 채택 (2026-09-26)
- 관련: [PR #1](https://github.com/padahkim/trizon/pull/1), 동작 세부는 `lib/quotes/AGENTS.md`

## 맥락

- 한국·일본·미국 주가와 USD/KRW·USD/JPY 환율이 필요하다.
- 개인 대시보드라 키 발급이나 비용 없이 쓸 수 있어야 한다. 몇 분 늦은 시세로 충분하다.

## 결정

- 주가와 환율 모두 `yahoo-finance2`로 받는다. 세 시장의 종목과 환율 심볼을 한 번의 요청으로 묶는다.
- 환율은 Yahoo가 실패하면 Frankfurter(ECB 기준, 키 불필요)를 쓴다.
- provider는 `QuoteProvider` 인터페이스(`lib/quotes/types.ts`) 뒤에 둔다. 다른 시세 소스로 바꿔도 계산과 화면은 그대로다.

## 버린 대안

- **시장별 공식·유료 시세 API:** 키 발급이나 비용이 들고, 시장마다 따로 붙여야 한다. 개인 대시보드에는 과하다.

## 감수하는 것

- 비공식 API라 429나 crumb 오류로 가끔 깨진다. 그래서 15분 캐시, 마지막 성공값 저장, 실패 뒤 1분 동안 재요청하지 않는 규칙을 둔다.
- Yahoo는 없는 거래소 조합에도 옛 시세를 돌려준다. 그래서 종목을 추가할 때 후보 중 가장 최근 시세를 고르고, 그것마저 오래됐으면 거부한다.
- Yahoo 검색은 한글·일본어 검색어를 거부한다. 종목명 검색은 별도 목록(한국투자증권 종목 마스터, JPX)으로 한다(`lib/symbols/AGENTS.md`).

## 다시 볼 조건

- Yahoo가 오래 막혀서 캐시로 버틸 수 없을 때.
- 증권사 API 연동(002의 v2 후보)으로 보유종목과 함께 시세도 받을 수 있게 될 때.
