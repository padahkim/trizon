# 003. 수익률은 증권사 화면과 같은 기준으로 계산한다

- 상태: 채택 (2026-09-26)
- 관련: [PR #1](https://github.com/padahkim/trizon/pull/1), 계산 규칙은 `docs/architecture.md`의 "금액·통화 모델"

## 맥락

- 해외 종목의 "수익률"은 기준에 따라 여러 개다. 거래통화 기준(주가만), 계좌통화 기준(환차손익 포함), 표시 통화 기준.
- 사용자는 증권사 앱의 숫자와 대조하면서 이 앱을 쓴다. 숫자가 다르면 어느 쪽이 맞는지 따져야 하고, 앱을 믿지 못하게 된다.

## 결정

- 종목은 **계좌통화** 기준으로 평가한다. 증권사 앱이 보여 주는 수익률과 같은 값이다.
- 그래서 해외 종목은 계좌통화 기준 매입금액(`costBasisHome`)을 받는다. 한국 계좌는 원화 매입금액, SBI는 取得単価(円換算)이다.
- 주가 수익률(거래통화 기준)도 옆에 보여 준다. 환율 효과와 주가 효과를 나눠 볼 수 있다.
- 합계는 계좌마다 계좌통화 금액을 현재 환율로 표시 통화에 모은다. 그래서 표시 통화를 원·엔·달러 중 무엇으로 바꿔도 총수익률(%)이 같다. 이 성질은 테스트로 고정한다.
- 시세를 못 받은 종목도 합계에서 빼지 않는다. 빼면 총자산이 실제보다 작게 나온다.

## 버린 대안

- **거래통화 기준만:** 입력이 쉽지만 환차손익이 빠져서 해외 종목 수익률이 증권사 화면과 다르다.
- **표시 통화 기준 매입금액(원↔엔 교차환율까지 반영):** 한 통화 관점의 "진짜" 수익률에 가깝다. 하지만 매입 시점의 교차환율이 필요한데, 증권사 어디에도 그 숫자가 없다. 표시 통화를 바꿀 때마다 총수익률도 달라진다.

## 감수하는 것

- 원↔엔 교차환율의 변동은 총수익률에 들어가지 않는다. 화면 툴팁으로 알린다.
- 미국 주식 평가액은 증권사가 쓰는 환율(매매기준율 등)과 0.5% 안팎 차이가 날 수 있다.
- 계좌통화 매입금액을 모르면 현재 환율로 환산하고, 환율 효과가 빠졌다고 표시한다(`fxEffectIncluded`).

## 다시 볼 조건

- 계좌를 넘어 하나의 통화 관점(예: 원화 기준 실질 수익)으로 총자산을 봐야 할 때.
