# 005. 테스트는 프레임워크 없이 `node --test`로 돌린다

- 상태: 채택 (2026-09-26)
- 관련: [PR #1](https://github.com/padahkim/trizon/pull/1), 지켜야 할 규칙은 루트 `AGENTS.md`의 "TypeScript 규칙"

## 맥락

- 테스트할 핵심은 순수 로직이다. 수익률 계산, 환율 환산, 금액 포맷, 종목코드 규칙, CSV·종목 목록 파서가 여기에 해당한다.
- Node(>= 22.18)는 빌드 없이 `.ts`의 타입만 지우고 바로 실행한다.

## 결정

- 테스트는 `node --test`로 `.ts`를 직접 실행한다. 테스트 프레임워크도, 린터도 쓰지 않는다. 정적 검사는 `tsc`뿐이다.
- 테스트는 네트워크 없이 돈다. 외부 의존은 가짜 provider·시계·파일 경로를 주입해서 대신한다.
- 실제 외부 응답은 `npm test`에 넣지 않고, 스모크 스크립트(`quote:smoke`, `symbols:smoke`)로 따로 확인한다.

## 버린 대안

- **Vitest·Jest:** 모킹·스냅샷 같은 기능이 있지만 의존성과 TS·ESM 변환 설정이 늘어난다. 지금 테스트하는 대상에는 필요 없다.

## 감수하는 것

- 타입 스트리핑으로 지울 수 있는 문법만 쓴다. enum·namespace·생성자 parameter property를 쓰지 못하고, 상대 import에 `.ts`를 붙인다.
- `lib/`는 Next 없이 돌아야 한다. `next`·`server-only`는 `lib/server.ts`에서만 import한다.
- 컴포넌트·화면 테스트는 없다. 화면은 앱을 띄워서 확인한다.

## 다시 볼 조건

- 화면이나 컴포넌트를 자동으로 테스트해야 할 때.
