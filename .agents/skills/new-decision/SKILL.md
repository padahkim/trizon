# 결정 기록 쓰기

규칙의 원본은 루트 `AGENTS.md`의 "지침 파일 관리"다. 먼저 읽는다. 이 스킬은 순서만 정한다.

1. **쓸지 정한다.** 무엇을 하기로 했고 무엇을 버렸는지 남길 결정이면 쓴다. 지금 어떻게 동작하는지는 `docs/architecture.md`나 폴더별 `AGENTS.md`에 쓴다.
   - 바꾸려는 결정의 기록이 이미 있으면 먼저 읽는다. 루트 `AGENTS.md`의 "결정 기록" 목록에서 찾는다.
2. **번호를 받는다.** `npm run decision:next`를 돌린다.
   - 다른 PC에서 올린 브랜치까지 보려면 먼저 `git fetch`한다.
   - "번호 중복"이 나오면 사용자에게 알린다. 나중에 머지하는 쪽이 번호를 바꾼다.
3. **틀대로 쓴다.** 이 폴더의 `template.md`를 `docs/decisions/NNN-짧은-영문.md`로 복사해서 채운다. 틀의 주석은 다 채운 뒤 지운다.
4. **등록한다.** 루트 `AGENTS.md`의 "결정 기록" 목록 끝에 기존 줄과 같은 모양으로 한 줄을 더한다. 옛 결정을 대체하면 "지침 파일 관리"의 규칙대로 옛 기록에도 표시한다.
5. **확인한다.** `npm run check`를 돌린다. 번호가 겹치거나, 목록에 빠졌거나, 없는 기록을 가리키는 곳이 있으면 `scripts/decisions.test.ts`가 실패하며 무엇을 고칠지 알려 준다.
