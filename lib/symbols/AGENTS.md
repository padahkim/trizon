# lib/symbols: 종목명 검색 목록

Yahoo 검색은 한글·일본어 검색어를 거부한다(`Invalid Search Query`). 그래서 공개 목록 두 가지를 받아 로컬 색인을 만든다. 키는 필요 없다.

## 소스 (`sources.ts`)

- **한국투자증권(KIS) 종목 마스터:** 매일 새벽 갱신된다. 국내 코스피·코스닥과 해외 나스닥·뉴욕·아멕스·도쿄를 합쳐 zip 6개를 받는다. URL 출처는 `github.com/koreainvestment/open-trading-api`의 `stocks_info/*.py`다.
  - 한국·미국 종목의 유일한 소스라서 **하나라도 실패하면 목록을 만들지 않는다.** 반쪽 목록이 하루 동안 남지 않게 하려는 것이다.
- **JPX 東証上場銘柄一覧(`data_j.xlsx`):** 월 1회 갱신된다. 일본어 종목명을 여기서 얻는다.
  - 실패해도 목록은 만든다. `warnings`에 사유를 남기고, 일본 종목은 KIS의 한글·영문명으로만 검색된다.

## 형식 (`parse.ts`)

파서는 텍스트와 XML만 받아서 네트워크 없이 테스트한다.

- **KIS 국내:** CP949 고정폭이다. 단축코드 9자리, 표준코드 12자리, 한글명 순이고, 끝에 뒷부분이 붙는다(코스피 227자, 코스닥 221자).
  - 한글명은 바이트 폭이 고정이라 디코딩한 글자 수가 줄마다 다르다. 그래서 **뒤에서부터** 자른다.
  - 뒷부분의 맨 앞 2자는 증권그룹이다. 수익증권(`BC`)과 신주인수권(`SW`·`SR`)은 뺀다.
  - 뒷부분 끝에서 15~6번째 자리는 시가총액(억원)이다. 이 값으로 `tier`(회사 규모)를 정한다.
  - 필드 규격은 위 KIS 저장소의 `kis_kospi_code_mst.py`에 있는 `field_specs`다.
- **KIS 해외:** CP949 탭 구분이다. 열은 [3] 거래소명, [4] 심볼, [6] 한글명, [7] 영문명, [8] 종류(2 주식, 3 ETP)다.
  - 슬래시 심볼(`BRK/B`, `ABR/D`)은 클래스 주식만 `BRK.B`로 남긴다. 우선주와 유닛은 Yahoo 표기가 달라서 조회되지 않는다.
- **JPX:** xlsx의 `sharedStrings.xml`과 `sheet1.xml`을 정규식으로 읽는다. 열은 위치가 아니라 머리글(`コード`, `銘柄名`, `市場・商品区分`, `規模コード`)로 찾는다.
  - 일본 종목은 JPX와 KIS를 코드로 합친다. JPX 갱신 뒤에 상장한 종목은 KIS에만 있다.
  - `PRO Market`은 뺀다(특정투자자 전용).
- **공통:** 폼이 받지 않는 코드는 목록에 넣지 않는다. 예를 들어 7자리 ETN `Q500067`이 여기 해당한다.
  - 판단은 `lib/domain/symbols.ts`의 `quoteSymbolCandidates` 규칙을 그대로 쓴다. 여기에 따로 적지 않는다.
- **압축:** zip과 xlsx는 `unzip.ts`가 `node:zlib`로 푼다. 크기는 central directory에서 읽는다(data descriptor 대응). zip64와 암호화는 다루지 않는다.
- **표시 이름:** 한국은 한글명, 일본은 日本語名, 미국은 한글명(없으면 영문명)이다. 나머지 이름은 `aliases`에 넣어 검색에만 쓴다.

## 검색 (`search.ts`)

- **정규화:** NFKC로 전각 문자를 맞추고, 소문자로 바꾸고, 공백을 뺀다.
- **순위:** 코드 일치 → 코드 앞부분 → 이름 일치 → 이름 앞부분 → 띄어 쓴 낱말이 모두 들어 있음.
- **같은 순위일 때:** 선호 시장(지금 고른 계좌 기준) → 보통주 → 큰 회사(`tier`) → 짧은 이름 순이다.
- **코드 표기:** `005930.KS`, `A005930`, `7203.T`, `brk-b`, `BRK/B`처럼 붙여 넣는 표기를 받는다.

## 캐시 (`service.ts`)

- **저장:** `data/symbols.json`에 저장한다. 처음 검색할 때 받고, 이때만 1초 안팎이 걸린다.
- **동시 요청:** 동시에 들어온 첫 검색들이 디스크 읽기와 다운로드를 한 번만 하도록 promise를 공유한다.
- **갱신:** 하루가 지나면 옛 목록으로 답하면서 뒤에서 새로 받는다.
- **실패하면:** 1분 동안 다시 시도하지 않는다. 옛 목록이 있으면 실패해도 계속 검색된다.

## 확인

- `npm test`는 합성 픽스처로 돈다. 테스트용 zip은 `unzip.test.ts`가 직접 만든다.
- 소스 형식이 바뀌었는지는 `npm run symbols:smoke -- 삼성전자 トヨタ`로 확인한다. 실제로 받아서 메모리에서만 검색하고, `data/`는 건드리지 않는다.
