# trizon

한국(KB·NH나무·토스)과 일본(SBI証券) 계좌의 주식을 한곳에 모아 총자산과 수익률을 보여주는 로컬 전용 대시보드.

## 실행

```bash
npm install
npm run dev          # http://localhost:3000
```

- `/holdings` 에서 증권사 앱의 잔고 화면을 보며 종목·수량·평균단가를 입력한다. 종목은 이름 일부(삼성전자·トヨタ·엔비디아·tiger 미국)나 코드로 검색해 고른다. 해외 종목은 계좌통화 기준 매입금액(원화 매입금액 / 取得単価(円換算))도 넣으면 환차손익까지 증권사 화면과 맞는다.
- `/sbi` 에서 SBI証券의 CSV 3개(実現損益·ポートフォリオ·配当・分配金)를 끌어다 놓으면 총 누적손익(실현손익 + 평가손익 + 배당·분배금)을 보여 준다. 받는 경로는 화면에 안내된다. 포트폴리오 CSV의 보유종목은 대시보드의 SBI証券 계좌에도 들어가며, 현재가는 자동으로 받으므로 사고팔았을 때만 다시 넣으면 된다(투자신탁은 CSV 기준가).
- 현재가·환율은 Yahoo Finance(비공식)에서 15분 캐시로 가져오고, 환율은 Frankfurter(ECB)로 폴백한다.
- 종목 검색 목록은 한국투자증권 종목 마스터(한국·미국·도쿄, 매일 갱신)와 JPX 東証上場銘柄一覧(日本語名, 월 1회 갱신)에서 받는다. 처음 검색할 때 한 번 몇 초 걸리고, 하루가 지나면 뒤에서 새로 받는다. 목록을 못 받아도 종목코드를 직접 입력하면 된다.

## 데이터

모든 데이터는 `data/` 에 있고 git 에서 제외된다. 백업은 이 폴더를 통째로 복사하면 된다.

| 파일 | 내용 |
|---|---|
| `data/portfolio.json` | 계좌와 보유종목 (직접 고쳐도 된다 — 형식이 깨지면 화면이 알려주고 파일은 건드리지 않는다) |
| `data/quotes-cache.json` | 마지막으로 받은 시세·환율 (지워도 된다) |
| `data/symbols.json` | 종목 검색 목록 (지워도 된다 — 다음 검색 때 다시 받는다) |
| `data/snapshots.jsonl` | 하루 한 줄 총자산 기록 (대시보드를 그날 처음 열 때 추가) |
| `data/sbi-imports.json` | `/sbi` 에 넣은 SBI CSV 원문 (종류마다 마지막 하나) |

검증·실험할 때는 `TRIZON_DATA_DIR=/다른/폴더 npm run dev` 로 실제 데이터와 분리한다. 계속 쓸 설정이면 `.env.example` 을 `.env.local` 로 복사해 적어 둔다.

## 개발

```bash
npm test             # 순수 로직 테스트 (node --test, 네트워크 없음)
npm run typecheck
npm run quote:smoke -- 005930 7203 AAPL   # 실제 시세 조회 확인
npm run symbols:smoke -- 삼성전자 トヨタ    # 실제 종목 목록을 받아 검색 확인
```
